Note d'usage : 

  Afin d'accéder à l'interface, il suffit d'aller dans le dossier interface.py et de lancer le programme. 
  
Remarque :

  Les onglets sont susceptibles de dépasser de l'écran, pouvant masquer certains éléments tels que la touche exécuter. Il suffit alors de déplacer   l'onglet ou de mettre celui-ci en plein écran
